# API 参考

以下接口仅用于文档展示，不提供真实服务。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回文档条目列表。

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

这是我自己设计的第二个示例接口，用来说明路径参数和返回字段。

- 请求方法：GET
- 请求路径：/api/docs/{id}
- 功能：根据编号返回一篇文档的详细信息。

### 参数说明

| 参数 | 位置 | 类型 | 说明 |
| --- | --- | --- | --- |
| id | 路径 | 整数 | 文档编号 |

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "page": "guide.md"
}
```

更多背景见 [关于本项目](about.md)，操作步骤见 [使用指南](guide.md)。
