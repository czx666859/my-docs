# 关于本项目

## 项目目标

实现从 Markdown 文档到公开网站的自动化发布。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs Material | 将文档构建成静态网站 |
| GitHub Actions | 自动执行安装、构建和部署 |
| GitHub Pages | 托管并提供网站访问地址 |

## 目录里各部分的作用

| 位置 | 说明 |
| --- | --- |
| `docs/` | 存放网站的 Markdown 源文件，是我真正需要编写的内容 |
| `mkdocs.yml` | 配置站点名称、主题和导航，其中 `nav` 决定左侧菜单的顺序 |
| `site/` | 构建后自动生成的网页，不手工修改，也不提交到仓库 |
| `.github/workflows/` | 保存自动部署的工作流配置 |
| `report/` | 保存个人实验报告和截图 |

## 我的理解

这四个工具各管一段：Markdown 负责写内容，MkDocs 负责把内容变成网页，Actions 负责在每次推送后替我执行构建，Pages 负责把构建好的网页放到公网上。四者连起来，就形成了"推送文档、自动构建、自动部署、网页更新"这条流水线。

想看具体操作，可以回到 [首页](index.md) 或阅读 [使用指南](guide.md)。
