## 我的实践目标

通过本次实践，我希望学会如何用 GitHub 自动构建并发布一个可以公开访问的文档网站，做到修改文档、推送代码之后，网页能自己更新，不再需要手工上传文件。

## 我的体会

以前我写完文档只能留在自己电脑里，别人想看还要另外发文件。这次把文档放进仓库，用 Actions 在云端构建，网站地址一直固定不变，每次推送都会得到最新内容。我觉得这种"内容写在源码里、网站自动生成"的方式，比手工维护网页省事得多，也更容易留下修改记录。
